# Bluetooth Workshops - Embedded systemen : Connecties

## Overzicht van de uitgewerkte workshops

1. **`ble_sig_services`**
   * Ontwikkeling van een IoT weerstation met officiële Bluetooth SIG 16-bit UUID's (Environmental Sensing `0x181A`).

2. **`ble_events_callbacks`**
   * Event-driven BLE sturing met `BLEServerCallbacks` en `BLECharacteristicCallbacks` (`onRead` / `onWrite`).

3. **`ble_realtime_notificaties`**
   * Realtime gegevens pushen via notificaties (Notify / CCCD `0x2902`) en potentiometer-uitlezing.

4. **`ble_web_bluetooth`**
   * Draadloze bediening en sensor-dashboard via de Web Bluetooth API in de browser (HTML/JavaScript).

5. **`ble_app_inventor`**
   * Eigen Android/iOS smartphone-app gebouwd met MIT App Inventor en de BluetoothLE extensie.

6. **`ble_pakketbox`**
   * Casusopdracht: slimme pakketbox met BLE-bediening via Web Bluetooth, automatisch interval met `millis()` en statusbevestiging via notify.
